# Aegis Vuldris Security Principles

## Authorized Testing

Aegis Vuldris is intended for security testing of AI systems that the tester owns or has explicit authorization to assess.

## Security by Design

Security should be implemented at multiple layers rather than relying exclusively on AI model behavior.

## Privacy by Design

Test data, credentials, personal information, model responses, and security findings must be handled carefully and should not be exposed unnecessarily.

## Evidence

Security findings should be reproducible and supported by sufficient evidence.

## Least Privilege

Components should receive only the permissions required for their function.
